    Methodology

    Rendered from the scoring rubric used on every run.

    Agent-Ready Score (pilot v0.1), 100 points

    Start at the homepage, as a fresh guest. Never sign in, enter an address, payment, or place an order.

    1. Access (20): homepage loads clean = 20; captcha/bot check passed = 10; blocked = 0.
    2. Search (20): search box found and relevant results for the query = 20; results irrelevant or needed retries = 10; failed = 0.
    3. Product page (20): opened a product page with price and Add to Cart visible = 20; needed workarounds (location/zip, option pickers unclear) = 10; failed = 0.
    4. Add to cart (20): item confirmed in cart with no interruption = 20; added after friction (modals, upsells, required options) OR a first attempt failed and a retry succeeded = 10; failed = 0.
    5. Reach checkout (20): reached checkout or guest-checkout entry = 20; sign-in wall with no guest option = 10; checkout page never finishes loading, or the step fails = 0. An email-only gate (you can continue with just an email; no password or account creation required, e.g. Home Depot 'Ready to checkout?', Wayfair's email step) counts as guest checkout: checkout 20, outcome guest_checkout, guest_checkout true, and no no_guest_checkout tag. (Decided 2026-10-21 by JC.)

    Also log: total actions taken, minutes, friction notes (popups, cookie banners, location prompts, upsells), where it broke.

    Run rules:

    • Start each daily run in a fresh browser session: clear cookies, site data, and cache, and close extra tabs, so the visit looks like a first-time guest.
    • Never sign in, enter an address, payment, email, or phone, or place an order. Stop at the first checkout screen.
    • If the checkout page never finishes loading, score checkout 0, not 10.
    • A first attempt that errors and then succeeds on retry scores the stage at the friction level (10), and the note names the error.
    • If a stage only passes by typing a URL directly (for example opening /checkout because the button spins), that stage scores 10 and the friction tag is url_workaround.
    • An upsell drawer or modal after add to cart always makes the cart stage 10, even if it doesn't block. A cookie banner or overlay that blocks a click until dismissed makes that stage 10.
